# Pull Request Template Standard

## Purpose

Define the minimum information a pull request provides so reviewers can evaluate scope, evidence, risk, and traceability efficiently.

## Scope

This standard covers the information requested by a pull-request template. It does not replace branch, review, or completion rules.

## Required Content

A pull request template MUST request:

- a concise summary of the change;
- linked work items or a statement that no tracked item applies;
- validation performed and its result;
- material risks, follow-up work, or deployment considerations; and
- evidence required by the applicable Definition of Done.

The template MAY include prompts specific to a repository's product, security, release, or operational context when they do not replace the governing standard.

## Use

The author MUST complete the prompts that apply or state why a prompt is not applicable. A template is an aid to review; it does not substitute for the evidence required to merge.
