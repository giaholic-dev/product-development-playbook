# Artifact Catalog

## Purpose

Provide a discoverable catalog of the artifact categories used by this Playbook and the repository locations that currently provide their governing examples.

This catalog is navigational. The [Artifact Standard](artifact-standard.md) governs artifact identity and classification.

| Category | Optional subtype or representative artifact | Primary location |
| --- | --- | --- |
| Documentation | Standards, practices, decision records, guides, records, and lifecycle documentation | [Standards](./), [practices](../practices/), and [lifecycle](../lifecycle/) |
| Template | Reusable starting material | [Templates](../../templates/) |
| Example | Illustrative applications | [Examples](../../examples/) |
| Implementation evidence | Source, configuration, test, or automation evidence when present | Repository implementation locations identified by the responsible work record |
| External evidence | Evidence retained outside the repository | Location linked by the responsible work or governing record |

The category names follow the Artifact Standard. Standard and Decision Record are Documentation subtypes; lifecycle documentation describes a document's responsibility, not another category. The table is representative and does not require an artifact merely because it is listed.

## Scope

This catalog covers artifact categories and representative repository locations. It does not govern artifact identity, classification, or work-item fields.

## Use

Use this catalog to locate the governing artifact type. Do not use it to assign a work-item field or to replace the source of truth for a specific artifact.
