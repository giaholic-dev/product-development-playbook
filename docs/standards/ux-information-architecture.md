# UX Information Architecture

## Purpose

Define how product information, content, functions, and navigation are organized to support intended user goals.

## Scope

This standard concerns product experience information architecture. It is distinct from the repository's [Documentation Information Architecture](documentation-information-architecture.md).

## Definition

UX Information Architecture is the intentional organization, labeling, hierarchy, and navigation of product information and functions so relevant actors can find, understand, and use them.

## Rules

An information-architecture decision MUST state the intended actors, goals, boundary, and evidence or assumptions it relies on. It SHOULD make important content, functions, terminology, and navigation relationships understandable without prescribing visual styling or technical implementation.

The chosen representation MAY be a site map, content model, navigation model, taxonomy, flow, or another suitable artifact. It is proportionate to the experience decision.

## Relationships

UX Information Architecture consumes UX Vision, User Journeys, Personas, User Flows, and validation evidence. It informs wireframes, prototypes, architectural constraints, and Product Backlog refinement.
