# Coding Standards

## Purpose

Define how a project establishes maintainable, consistent, and reviewable implementation conventions without prescribing a programming language or framework.

## Scope

This standard applies when a repository contains source code or executable configuration.

## Rules

A project with implementation code MUST document the language- and platform-specific conventions it adopts, including formatting, naming, structure, error handling, dependency use, security-sensitive practices, and validation expectations as applicable.

Local conventions MUST be discoverable, automatable where practical, and proportionate to the repository's risk and maturity. They MAY extend this standard but MUST NOT conflict with Repository Standards, Code Review Standard, Definition of Done, or applicable security and quality requirements.

A documentation-only repository MAY record this standard as not applicable.

## Evidence

Coding-convention evidence MAY include formatter or linter configuration, a language-specific guide, automated checks, review checklists, or documented exceptions.
