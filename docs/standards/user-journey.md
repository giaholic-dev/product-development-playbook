# User Journey

## Purpose

Define how a product documents an actor's end-to-end experience while pursuing a meaningful goal.

## Scope

This standard is independent of journey-map format, research method, or interface technology.

## Definition

A User Journey is an evidence-informed representation of the steps, contexts, needs, decisions, and pain points an actor experiences while pursuing a goal relevant to the product.

## Rules

A journey MUST identify the actor, goal, boundaries, and evidence or assumptions it relies on. It SHOULD identify material stages, interactions, and opportunities without prescribing an interface solution.

A journey MAY describe a user, operator, customer, or other relevant actor. It is selected when it improves an experience decision; it is not a mandatory artifact for every product.

## Relationships

Journeys inform UX Vision, User Flows, validation, and Product Backlog refinement. They do not replace the Users standard or define Product Scope.
