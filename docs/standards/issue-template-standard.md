# Issue Template Standard

## Purpose

Define the minimum information issue templates request so proposed work is understandable, traceable, and ready for responsible assessment.

## Scope

This standard covers the information requested by an issue template. It does not replace work-item classification, readiness, or completion rules.

## Required Content

An issue template MUST request:

- the problem, opportunity, or intended outcome;
- scope and material exclusions;
- acceptance evidence or decision criteria;
- dependencies, constraints, risks, or open questions; and
- a prompt to classify the item using the adopted work-item model when applicable.

The template MAY be specialized for defects, incidents, research, or other legitimate work types. It MUST not require speculative implementation detail before it is needed.

## Use

The author MUST provide available evidence or explicitly identify the uncertainty. A template does not make an item ready by itself; readiness remains governed by the [Definition of Ready](definition-of-ready.md).
