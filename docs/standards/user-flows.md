# User Flows

## Purpose

Define a User Flow as a representation of the meaningful interactions an actor takes to pursue a product goal.

## Scope

This standard is independent of diagram notation, interface technology, and delivery method.

## Definition

A User Flow describes the relevant steps, decisions, alternate paths, and completion conditions for an actor pursuing a goal through the product.

## Rules

A User Flow MUST identify the actor, goal, boundary, and decision it supports. It SHOULD identify meaningful choices, failure or alternate paths, and dependencies on information or other actors when they affect the experience.

A flow describes intended interaction behavior; it does not prescribe visual design, technical architecture, or implementation sequence. It is created when needed to clarify a material experience or product decision.

## Relationships

User Flows may be derived from UX Vision, User Journeys, Personas, Product Scope, and validation evidence. They inform information architecture, prototypes, and Product Backlog refinement.
