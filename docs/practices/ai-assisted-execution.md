# AI-assisted Execution Practice

## Purpose

Offer non-normative guidance for applying the AI Collaboration Standard to a material work item.

## Use

1. Define the work item's purpose, expected evidence, owner, and manual next action.
2. State the authorized context and information boundary supplied to AI.
3. State the AI task and authority boundary.
4. Validate proposed output against the governing artifacts.
5. Record the accountable disposition, review, and follow-up.
6. Continue manually if AI capability is unavailable.

This practice does not require a provider, model, prompt format, or integration.
