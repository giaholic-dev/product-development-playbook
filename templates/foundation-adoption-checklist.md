# Foundation Adoption Checklist Template

Use this checklist with the [Foundation Phase](../docs/lifecycle/01-foundation.md).

- [ ] Repository purpose, owner, and access are recorded.
- [ ] Repository Standards and applicable detailed standards are adopted.
- [ ] Work classification and planning model are usable.
- [ ] Documentation language, entry point, and navigation are established.
- [ ] Workflow, readiness, review, and completion gates are identified.
- [ ] Execution mode, AI authority boundaries, or a manual-only choice are recorded.
- [ ] Exceptions, unresolved decisions, owners, and reassessment conditions are recorded.
